Say it like this

  1. It is a tool-first interface: the agent uses official tools instead of burning tokens guessing how Android works.
  2. It works in any terminal, with any agent harness, and in CI.
  3. preview, device remote and profiler are what close the verification loop on UI, real devices and performance.
  4. studio needs the Android Studio Quail preview with a project open; the memory-leak subcommand was announced as "coming soon".
  5. Vendor figures (77% faster UI tasks with preview) are internal measurements.
