ACP vs MCP

Use it when: asked what protocols sit between the IDE, the agent and your tools.

Say it like this

  1. ACP standardizes how an editor talks to a coding agent: local agents run as subprocesses over stdio, remote ones over HTTP or WebSocket.
  2. MCP standardizes how an agent reaches tools and data; ACP reuses MCP's JSON representations where possible and adds types for coding features such as diffs.
  3. Agents can also just run command-line tools, which is how the Android CLI is used.
  4. Practical consequence: an editor that speaks ACP can host many agents (Android Studio supports 40+); an agent that speaks MCP can use many tool servers.
