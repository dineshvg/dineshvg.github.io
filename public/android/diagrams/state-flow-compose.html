State flow: data to Compose

Use it when: asked how data reaches the screen, or where state should live.

flowchart LR
  DB["Database or network"] -->|"Flow"| REPO["Repository"]
  REPO -->|"Flow"| VM["ViewModel with stateIn"]
  VM -->|"StateFlow"| UI["Composable: collectAsStateWithLifecycle"]
  UI -->|"events as lambdas"| VM
  VM -->|"suspend call"| REPO

Say it like this

  1. The data layer exposes Flows for changing data and suspend functions for one-shot calls.
  2. The ViewModel owns coroutines (viewModelScope) and exposes an immutable StateFlow.
  3. The composable collects lifecycle-aware; it holds no business state, only UI state it can hoist.
  4. Events go up as lambdas; state comes down as parameters: single source of truth.
