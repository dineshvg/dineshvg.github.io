System design framework

Use it when: given an open-ended mobile design prompt in a 45-minute round.

flowchart LR
  A["1 Clarify requirements<br/>5 min"] --> B["2 Constraints<br/>offline, security, scale, team<br/>5 min"]
  B --> C["3 Layers and modules<br/>10 min"]

  D --> E["5 Security and privacy<br/>5 min"]

Say it like this

  1. Spend the first ten minutes on requirements and constraints; say what you assume.
  2. Draw layers and modules before details; name the single source of truth.
  3. Cover data flow and failure states: offline, conflicts, retries.
  4. Cover security and privacy explicitly; do not wait to be asked.
  5. Finish with how you test and release it, then the two biggest risks and what you gave up.

Source
